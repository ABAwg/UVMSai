**Формула Байеса**

\[
P(D\mid +)=\frac{P(+\mid D)\;P(D)}{P(+\mid D)\;P(D)+P(+\mid \neg D)\;P(\neg D)}
\]

где  

* \(P(D)=0{,}01\) – доля дефектных изделий (превалентность).  
* \(P(+\mid D)=0{,}95\) – **чувствительность** теста (вероятность «положительного» сигнала, если изделие действительно дефектное).  
* \(P(+\mid \neg D)=0{,}05\) – вероятность ложноположительного сигнала (детектор помечает исправное изделие как дефектное).  

Подставляем числа:

\[
\begin{aligned}
\text{числитель} &=0{,}95 \times 0{,}01 = 0{,}0095,\\[4pt]
\text{знаменатель} &=0{,}0095 + 0{,}05 \times 0{,}99 = 0{,}0095 + 0{,}0495 = 0{,}059,\\[4pt]
P(D\mid +) &= \frac{0{,}0095}{0{,}059}\approx 0{,}1610\;(\text{≈ 16,1 %}).
\end{aligned}
\]

Таким образом, **при положительном сигнале вероятность того, что изделие действительно дефектное, составляет около 16 %**.  
Заметьте: это **не** чувствительность (которая 95 %) – это постериорная вероятность дефекта, получаемая из условия «положительный результат».

## Проверка на 10 000 изделий (симуляция)

```python
import random

N = 10_000
prevalence = 0.01          # P(D)
sensitivity = 0.95         # P(+|D)
false_pos_rate = 0.05      # P(+|¬D)

defects = 0
positives = 0
true_positives = 0

for _ in range(N):
    # определяем, дефектное ли изделие
    is_defect = random.random() < prevalence
    # генерируем сигнал детектора
    if is_defect:
        positive = random.random() < sensitivity
    else:
        positive = random.random() < false_pos_rate

    if is_defect:
        defects += 1
    if positive:
        positives += 1
        if is_defect:
            true_positives += 1

# эмпирическая оценка P(D|+)
empirical = true_positives / positives if positives else 0

print(f"Дефектных изделий: {defects}")
print(f"Положительных сигналов: {positives}")
print(f"Истинно‑положительных: {true_positives}")
print(f"Эмпирическая P(D|+): {empirical:.4f}")
```

### Ожидаемый результат (теоретический расчёт)

| Показатель                | Ожидаемое значение |
|---------------------------|--------------------|
| Дефектных изделий (`defects`) | ≈ 100 |
| Положительных сигналов (`positives`) | ≈ 590 |
| Истинно‑положительных (`true_positives`) | ≈ 95 |
| Эмпирическая \(P(D\mid +)\) | ≈ 0.1610 (≈ 16 %) |

При запуске кода на 10 000 случайно сгенерированных изделий вы получите значения, очень близкие к этим теоретическим цифрам (некоторые отклонения из‑за случайности). Это подтверждает правильность расчёта по формуле Байеса.
