# UVMS AI v1.2.0 — обновление с v1.1.0 на Windows

Это самый безопасный путь, если у тебя уже есть рабочая v1.1.0 с настроенным OpenRouter и данными.

## Что сохранить из старой папки

Не отправляй и не публикуй эти файлы. Локально сохрани:

- корневой `.env` — там твои backend-настройки и OpenRouter key;
- `services/api/uvms_ai.db`, если твои текущие пользовательские данные реально хранятся именно в этом SQLite-файле;
- `storage/`, если там лежат загруженные файлы и ты хочешь сохранить их локально.

## Рекомендуемый способ

1. В старой v1.1.0 запусти `QUICK_STOP_WINDOWS.bat`.
2. Распакуй v1.2.0 **в новую отдельную папку**, не поверх старой.
3. Скопируй старый корневой `.env` в корень новой v1.2.0.
4. Если нужны старые локальные данные, скопируй старую БД/`storage` в соответствующие места новой папки до запуска.
5. Запусти `QUICK_SETUP_WINDOWS.bat` и дождись `All setup checks passed.`
6. Запусти `QUICK_RUN_WINDOWS.bat`.
7. Для iPhone запусти `QUICK_RUN_MOBILE_WINDOWS.bat`, затем открой QR в актуальном Expo Go.

## OpenRouter в v1.2

Старую рабочую настройку можно оставить. Если у тебя:

```env
UVMS_ENV=development
UVMS_AI_PROVIDER=auto
OPENROUTER_API_KEY=...
```

то v1.2 сам выберет OpenRouter для live text. Можно также явно поставить `UVMS_AI_PROVIDER=openrouter`.

Ключ должен оставаться только в корневом `.env`. Никогда не переносить его в `EXPO_PUBLIC_*` или frontend-код.

## Что проверить первым на iPhone

- В шапке чата написано `OpenRouter live`, а не `Demo AI`.
- Вопрос на русском получает нормальный живой ответ, а не шаблон `Welcome to the UVMS AI demo`.
- `**жирный текст**`, списки и code blocks визуально рендерятся, а не показываются сырыми Markdown-символами.
- `+` открывает компактное меню Photo / Camera / File / Library / Voice / Search / Image.
- Stop, Retry/Regenerate, Branch и Share работают.
- Фото из галереи и камеры доходят в чат и могут анализироваться текущим backend vision flow.

## Если что-то не так

Не меняй сразу код. Сначала пришли мне:

- скрин ошибки;
- окно API/Expo, если там есть ошибка;
- результат `http://<IP-ПК>:8002/live` на iPhone Safari;
- что показывает статус в шапке: `OpenRouter live` или `Demo AI`.
